Independent personal project

My medical history, in one place.

Personal Health History is a private, noncommercial application being developed by an individual exclusively to access, organize, and visualize their own medical records.

In development. The proposed features and healthcare connections are not operational yet. This public site contains policy information only; it does not accept or host medical records.

What the application is intended to do

With my authorization through a participating healthcare provider, the application is intended to retrieve available, read-only health data using SMART on FHIR. Planned features include a local longitudinal record, interactive laboratory trends, medical timelines, and source-supported summaries.

The application is for my personal use, not for commercial distribution, use by other patients, or clinical decision-making. Actual data availability depends on each provider and its supported access.
